# [@yummacss/play](https://play.yummacss.com)

Sandpack-based playground for Yumma CSS with Monaco Editor.

## Documentation

Head over to [yummacss.com](https://www.yummacss.com) for the full documentation.

## Built with

- [yummacss](https://www.npmjs.com/package/yummacss) - A CSS framework for the web with abbreviated styles.
- [@yummacss/api](https://www.npmjs.com/package/yummacss) - Yumma CSS utility classes for all your development needs.
- [next](https://www.npmjs.com/package/next) — An advanced React framework.
- [@codesandbox/sandpack-react](https://www.npmjs.com/package/@codesandbox/sandpack-react) - Sandboxes that run in the browser.
- [@monaco-editor/react](https://www.npmjs.com/package/@monaco-editor/react) - The code editor that powers VS Code.
